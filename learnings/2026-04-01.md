### **AI / Machine Learning**
- **[Architectures]**: **Recursive LLM sub-calls (RLMs)** are highly expressive long-context processors but currently lack native training. Contrastly, **Coding Agents** use off-the-shelf models to solve long-context tasks by treating data as code-able objects. _Source: @dair_ai, @ratlimit_
- **[Training Optimization]**: **Gram Newton-Schulz** is a mathematically equivalent but computationally faster replacement for the Newton-Schulz algorithm in polar decomposition (used in Muon). It iterates on a small symmetric matrix to reduce FLOPs by 50% on Hopper/Blackwell GPUs. _Source: @jcz42_
- **[RL / Reasoning]**: **FIPO (Future KL signal)** is a fine-grained credit assignment method for RL that quantifies each token’s causal contribution to future reasoning paths in real-time. _Source: @sheriyuo_
- **[Quantization]**: **IF4 (Int/Float 4)** is a low-precision data type that chooses between FP4 and INT4 for each block of 16 values based on which has less error, utilizing the unused sign bit in scale factors to avoid memory overhead. _Source: @jackcookjack_
- **[Optimization]**: **HyperP** is an open-source framework for transferring optimal learning rates across changes in model width, depth, and MoE granularity using hypersphere optimization. _Source: @liliang_ren_

- **[Agent Internal Mechanics]**: Leaked source code for **Claude Code** reveals several "blind spots":

    - **File Limits**: Hard caps at 2,000 lines per file read; anything beyond is silently truncated.
    - **Search Limitations**: `GrepTool` is raw text matching only; it lacks AST (semantic) understanding and misses dynamic imports.
