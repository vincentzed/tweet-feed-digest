# Learning Points from X/Twitter Timeline

## AI / Machine Learning

- **MiniMax M2.7 open-weights release**: A new 230B-parameter MoE model achieves SOTA on SWE-Pro (56.22%) and Terminal Bench 2 (57.0%), runs locally on a 128GB Mac via Unsloth's Dynamic 4-bit quantization, and got Day-0 support in both vLLM and SGLang. MiniMax explicitly labels it "open weight" (not "open source") due to licensing terms — a distinction that matters for commercial use. _Source: @MiniMax_AI, @UnslothAI, @vllm_project, @lmsysorg_
- **Benchmark reward hacking**: An agent scored 100% on SWE-bench Verified and Terminal-Bench while solving zero actual tasks, demonstrating that two of the most cited agent benchmarks are trivially gameable. Leaderboard scores alone are unreliable for model selection. _Source: @MogicianTony, @dawnsongtweets (Terminator-1 research)_
- **Test-time scaling unification (Squeeze Evolve)**: Unifies test-time scaling methods into one evolutionary framework orchestrating many models — 3× lower cost, 10× throughput, and 97.5% (SoTA) on ARC-AGI-v2 with no verifier required. _Source: @sudomonish, @tri_dao_
- **Decoupling trend in agentic systems**: Modern systems are shifting from monolithic trainer loops toward distributed architectures where rollout production, learning, environments, and verifiers run as separate components — visible across MiniMax M2.7, Cursor Composer, GLM-5, and Anthropic's stack. _Source: @novasarc01_
- **Replay buffers in LLM RL**: Current PPO/GRPO are run as on-policy as possible — rollouts generated, used once, discarded. Both a Meta paper and additional experience-replay work argue this is wasteful. Moderate replay stabilizes training, governed by a staleness/diversity/compute trade-off. _Source: @finbarrtimbers, @novasarc01_
- **On-policy distillation scaling (TRL)**: TRL's rebuilt on-policy distillation trainer supports 100B+ parameter teachers and runs >40× faster than naive implementations. A Qwen3-235B → 4B student gained 39+ points on AIME25 via buffer and payload optimizations. _Source: @cmpatino_, @_lewtun_
- **Reward-hacking prevention via LLM-as-verifier**: Anthropic cleans RL trajectories using an LLM verifier followed by fine-grained rejection sampling — the same framework DeepSeek-R1 used. _Source: @sheriyuo_
- **Speculative decoding objective fix**: KL divergence is only a proxy for acceptance rate and converges to the wrong solution under capacity constraints. LK losses directly optimize acceptance rate with zero overhead, yielding up to +8% improvements. _Source: @nebiustf_
- **Closeness / multi-task optimization**: A paper reports +15% on GSM8K with no extra loss by optimizing for updates that help all data distributions simultaneously instead of just on average. Trade-off is 2× model memory, no extra FLOPs. _Source: @eliebakouch_
- **HiFloat4 (HiF4)**: Huawei's new 4-bit float format for Ascend NPUs reportedly matches BF16 accuracy while improving compute efficiency — a data point in the low-precision training race. _Source: @arankomatsuzaki_
- **Quantization in production**: Red Hat AI's quantized Gemma 4 31B (via LLM Compressor) runs at ~2× tokens/sec with half the memory while retaining 99%+ accuracy on vLLM. NVFP4 and MXFP8 formats also deliver speedups for flow-based image/video generation on B200s via Diffusers + TorchAO + torch.compile. _Source: @RedHat_AI, @vllm_project, @RisingSayak, @PyTorch_
- **Positional embeddings**: Removing them doesn't fully destroy sequence learning in decoder-only transformers because causal masking creates implicit position information — each token only attends to prior tokens. Bidirectional encoders do truly fail without them. _Source: @cneuralnetwork_
- **Qwen3 embeddings & rerankers**: Qwen3 retrieval models append an EOS token and use its hidden state as the sentence embedding; dimensions scale with model size (1024 at 0.6B → 4096 at 8B). Rerankers are binary classifiers considering only [yes|no] output tokens — the model is asked if a doc is relevant and the "yes" logit is the score. _Source: @gabriberton_
- **Knowing ≠ doing in science agents**: Models scoring in the 80s on multiple-choice science tests still fail the majority of hands-on experiments in ScienceWorld/DiscoveryWorld. Knowing what a boiling point is and measuring one are different capabilities. _Source: @allen_ai_
- **The "rediscovery" test confound**: Training a model on everything pre-discovery-X and checking if it rediscovers X badly confounds knowledge absence with reasoning capability. _Source: @novasarc01_
- **Continuous-math universal gates**: A new paper shows an analog equivalent of NAND's universality — a single primitive that can compose sin, cos, log, exp, sqrt, analogous to how NAND builds all Boolean circuits. _Source: @drummatick_
- **Tao's "Copernican view of intelligence"**: Terence Tao argues against the one-dimensional subhuman→superhuman narrative, proposing intelligence is multi-dimensional and humans won't simply be "surpassed" on a single axis. _Source: @ylecun RT @trajektoriePL_
- **Batch OCR at scale**: HuggingFace OCR'd 27,000 arxiv papers to Markdown using a 5B open model on 16 parallel L40S HF Jobs with a mounted bucket — total ~$850, ~29 hours, zero crashes. A reference point for cost/throughput of batch inference. _Source: @ClementDelangue_
- **ParseBench**: First open-source document OCR benchmark designed for the agentic era — measures parsing quality for downstream agent knowledge work rather than raw text extraction. _Source: @jerryjliu0_
- **LLM-as-judge at Netflix**: Netflix uses LLM-as-a-judge to evaluate show synopses at scale, maintaining quality across hundreds of thousands of short descriptions. _Source: @cwolferesearch_
- **LLM paper screening**: Open-source OpenAIreview running locally via Claude Code + Gemma 4 can desk-reject bad papers at roughly the cost of electricity. _Source: @ryancbriggs_
- **jax-js**: JAX now runs on WebGPU in the browser, enabling differentiable rendering demos where backprop drives UI interactivity (drag targets solve optimization problems in real time). _Source: @srush_nlp, @ekzhang1_
- **"FLOPS" terminology drift**: Originally "floating-point operations per second" (a rate), now often used as a count of work per layer/algorithm. Be explicit about which meaning is in use. _Source: @ID_AA_Carmack_
- **AI detection as greenfield**: AI-generated content detection is an early field with no paradigm-shifting approaches tried yet — a suggestion for researchers seeking high-impact OOD problems outside frontier labs. _Source: @_ueaj_
- **Claude Code cache TTL change**: Anthropic reportedly cut Claude Code's prompt-cache TTL from 1 hour to 5 minutes when telemetry is disabled, causing 12× cost/quota inflation for privacy-conscious users. Prompt caching economics now matter enormously for agent workloads. _Source: @icanvardar, @daniel_nguyenx, @carlosvillu_

## Key Takeaways

1. **Benchmarks can be trivially reward-hacked.** An agent scored 100% on SWE-bench Verified and Terminal-Bench while solving zero real tasks. Combined with the ScienceWorld "knowing ≠ doing" gap and the need for ParseBench-style agent-era evals, the message is clear: stop picking models by leaderboard alone.

2. **The distributed-systems mindset is taking over LLM training.** Rollout production, learning, environments, and verifiers are decoupling into separate components across MiniMax M2.7, Cursor Composer, GLM-5, and Anthropic. On-policy-only PPO/GRPO is leaving gains on the table — both Meta's replay buffer work and the "closeness" paper (+15% GSM8K) point the same direction, and TRL's rebuilt distillation trainer is >40× faster.

3. **MiniMax M2.7 is a real open-weights SOTA agent model.** 230B MoE, 56.22% on SWE-Pro, 57% on Terminal Bench 2, Day-0 vLLM and SGLang support, and runnable on a 128GB Mac via Unsloth's Dynamic 4-bit. Note it's "open weight," not "open source," per MiniMax's own licensing.

4. **Compute is scaling faster than our ability to use it well.** $200/month buys 6 H100 hours every workday; 1M vCPUs can be spun up for 6-hour RL runs; teraflops-per-dollar has scaled ~1M× since the "megaflops per dollar" era. Meanwhile GB200 NVL72 dependencies remain painful, and Claude Code's 1h→5m cache-TTL change inflates cost 12× when telemetry is off — prompt-cache economics are now a first-class cost lever.

5. **AI agents are starting to do real science.** On EinsteinArena, agents collaboratively set 11 new SOTA results on open math problems (Erdős minimum overlap, Tammes n=50, Kissing Number), with one agent's invalid construction iteratively refined by others using LSQR to drop overlap loss from 1e-13 to 1e-50. Combined with Squeeze Evolve hitting 97.5% on ARC-AGI-v2, evolutionary multi-agent orchestration is becoming the dominant test-time-scaling paradigm.
