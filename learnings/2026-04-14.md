# Learnings - 2026-04-14 17:28

# Learning Points from Timeline

## AI / Machine Learning

- **On-policy RL inefficiency**: PPO and GRPO typically generate rollouts, use them for a single gradient update, then discard them — wasteful when rollouts are expensive. Replay-buffer approaches from classical deep RL are being rediscovered, with researchers oscillating between on-policy (when training is unstable) and off-policy (when rollouts are expensive). The trade-off is governed by staleness, diversity, and compute. _Source: @finbarrtimbers, @novasarc01, @neev_parikh_

- **Qwen3 embeddings architecture**: Qwen3 text-only models are fine-tuned for retrieval and reranking by appending an EOS token whose output hidden state is used as the embedding. Embedding dimensions scale with model size: 1024-dim for 0.6B up to 4096-dim for 8B. _Source: @gabriberton_

- **Reranker binary classification**: Cross-encoder rerankers effectively work as binary classifiers producing only [yes|no] tokens, using the "yes" logit as the relevance score. _Source: @gabriberton_

- **Contrastive retrieval false negatives**: Text retrieval datasets have many false negatives; a common fix is masking out samples from the loss when they might be false positives (roughly based on their loss value). _Source: @gabriberton_

- **"Unsupervised" video segmentation isn't**: Unsupervised Video Object Segmentation (UVOS) is called "unsupervised" despite using heavy supervision — "unsupervised" in vision often means something different than in other fields. _Source: @gabriberton_

- **Visual Late Chunking (ColChunk)**: A late-interaction retrieval approach achieving >90% storage reduction with a 9-point nDCG@5 improvement over single-vector models for visual document retrieval. _Source: @lateinteraction / paper by @_reachsumit_

- **Hugging Face Kernels Hub**: A new unified repo type on HF Hub for sharing precompiled GPU kernels (pre-built for specific GPU/PyTorch/OS combinations) across CUDA, ROCm, XPU backends. Multiple kernel versions coexist in one process with torch.compile compatibility, reporting 1.7x–2.5x speedups over PyTorch baselines. _Source: @ClementDelangue, @abdennacer0, @RisingSayak_

- **Speculative decoding is lossless**: EAGLE, DFlash, and MTP variants produce identical outputs modulo minor numerical differences — no accuracy drops. _Source: @bnjmn_marie_

- **DDTree speculative decoding**: Accelerates speculative decoding by drafting a tree with a single block-diffusion pass, then verifying multiple continuations together. _Source: @liranringel via @jeremyphoward_

- **LK losses beat KL for draft training**: KL divergence is only a proxy for acceptance rate and converges to the wrong solution under capacity constraints. Directly optimizing acceptance rate yields up to +8% gains with zero overhead. _Source: @nebiustf_

- **DFlash on Kimi-K2.5**: Achieves acceptance length between 4.0 and 6.3 on datasets using SGLang. _Source: @elliotarledge_

- **LLM-as-a-verifier for agents**: Test-time scaling helps agents, but picking the winner among candidates is the bottleneck. Using an LLM as verifier extracts cleaner signal and achieves SOTA on agentic benchmarks. _Source: @Azaliamirh via @_arohan__

- **LLM-as-judge in production**: Netflix uses LLM-as-judge to evaluate show synopses at scale (hundreds of thousands of titles), illustrating judge models deployed for quality control where human review doesn't scale. _Source: @cwolferesearch_

- **RLAD (Reasoning with Learned Abstractions)**: Uses model summaries of rollouts to learn reusable abstractions for reasoning models. _Source: @charles_irl_ (Singh, Salakhutdinov, Kumar, Finn)

- **Squeeze Evolve**: Unifies test-time scaling methods into one evolutionary framework orchestrating many models. Achieves 3x lower cost, 10x throughput, and 97.5% (SOTA) on ARC-AGI-V2 without a verifier. _Source: @sudomonish via @tri_dao_

- **Training dynamics — closeness of optima**: Measuring distance between local optima of training vs task distributions, aiming for updates good across all data rather than on average. Reports +15% on GSM8K at equal loss, costing 2x model memory (no extra FLOPs). _Source: @eliebakouch citing @rosinality_

- **AR vs diffusion LMs**: Autoregressive models are trained to agree with what they generate, and serving stacks preserve that structure. Diffusion LMs often do neither, making AR's structural simplicity a real advantage. _Source: @Chenfeng_X via @james_y_zou_

- **Sub-32B open-weights match GPT-5**: On the Artificial Analysis Intelligence Index, Qwen3.5 27B (Reasoning) matches GPT-5 (medium) at 42, and Gemma 4 31B (Reasoning) matches GPT-5 (low) at 39. _Source: @ArtificialAnlys_

- **Gemma 4 quantization**: Red Hat's LLM Compressor-quantized Gemma 4 31B runs ~2x tokens/sec with half the memory and 99%+ accuracy retention on vLLM. _Source: @RedHat_AI via @vllm_project_

- **Hadamard rotation divergence in FP8 DSA**: vLLM doesn't use Hadamard rotation for indexer score in FP8 with DSA; SGLang does — the accuracy impact is an open empirical question. _Source: @eliebakouch_

- **NVFP4/MXFP8 on B200 for flow models**: Diffusers + TorchAO with `torch.compile` deliver meaningful speedups on modern image/video flow models when FP4/FP8 recipes are tuned correctly. _Source: @RisingSayak via @PyTorch_

- **Chandra-OCR-2 throughput**: vLLM powers a 5B OCR model at ~60 papers/hour per L40S GPU across 16 parallel jobs. _Source: @vllm_project / @PyTorch_

- **OCR quality, not speed, is the bottleneck**: At scale, validating VLM OCR output (detecting repeated-token errors and hallucinations) is harder than the OCR itself. _Source: @HarveenChadha_

- **Batch OCR economics**: 27,000 arXiv papers OCR'd into Markdown using an open 5B model on 16 parallel L40S GPUs via HF Jobs with a mounted bucket — $850 total, ~29 hours, zero crashes. _Source: @ClementDelangue_

- **Gemini Robotics-ER 1.6**: Google DeepMind's new SOTA embodied robotics model focuses on visual and spatial reasoning, with multi-view reasoning that fuses live camera streams from multiple angles to understand a scene, pinpoint objects, and determine task completion. Exposed via the Gemini API. _Source: @GoogleDeepMind / @OfficialLoganK_

- **ColGrep 1.2.0 hybrid search**: Incorporates BM25 trigrams to enhance multi-vector models with hybrid search, printing relative paths by default for fewer tokens per result. _Source: @raphaelsrty via @lateinteraction_

- **Compute bottleneck shift — CPUs, not GPUs**: Per Dylan Patel, CPUs are now the constraint in AI infrastructure. Agentic systems add significant non-GPU work around each model call (tool orchestration, API calls, scheduling, retrieval, verification, queuing) — most CPU-bound. _Source: @ivanburazin citing @dylan522p, @novasarc01_

- **AI science agents still fall short**: Allen AI's evaluations show top AI science agents still fail challenges human scientists solve most of the time. On ScienceWorld, top models went from <10% at launch to low 80s in early 2025, yet models that ace multiple-choice science tests still fail >90% of matching virtual experiments — knowing and doing remain distinct. _Source: @allen_ai_

- **DeepSeek Engram critique**: A Zhihu analysis argues DeepSeek's "Engram" external memory is effectively regularization — gains come from context-aware gating (dynamic feature adjustment) and an extra residual pathway (better gradient flow), not stored memory content. _Source: @teortaxesTex_

- **Retrieval vs reasoning**: Retrieving a stored reasoning trace resembles human reasoning until you hit novel territory — memorizing every human reasoning trace from 10,000 BC would let you automate that era but couldn't invent modern civilization. _Source: @fchollet_

- **JSON is token-inefficient for LLMs**: Braces and quotes meaningfully raise inference cost; TOML, YAML, or custom schemas save real money at scale. _Source: @Thom_Wolf_

- **MiniMax open-sources music skills**: Three music-agent skills released — one-line prompt to full track, with the agent auto-choosing original/instrumental/cover mode. _Source: @MiniMax_AI_

- **Anthropic Fellows Program**: Four-month fully funded AI safety/security/impact fellowship — $3,850/week stipend plus ~$15K/month compute plus mentorship. _Source: @ImadeIyamu_

- **Claude found a real CVE**: Claude identified a vulnerability in Firecracker VMM allowing a local guest user with root privileges to crash the VMM or potentially execute code on the host. _Source: @sweis_

## Software Engineering

- **The bottleneck is merging, not generation**: A "50% faster Liquid via autoresearch" PR sat unmerged for a month — code generation has outpaced human review and integration bandwidth. The frontier of developer productivity is now in review, testing, and merging. _Source: @nateberkopec_

- **SWE-bench Verified can be reward-hacked**: Both SWE-bench Verified and Terminal-Bench have been scored 100% by an agent that solved zero tasks. Audit benchmarks before trusting leaderboards. _Source: @MogicianTony via @ying11231_

- **ParseBench**: First open-source document OCR benchmark for the agentic era, measuring parsing quality for agent knowledge work on real-world files. _Source: @jerryjliu0 via @charles_irl_

- **liteparse for agent document ingestion**: LlamaIndex released liteparse, a free OSS parser designed for agents with native OCR/screenshotting fallback for visually complex documents. _Source: @jerryjliu0_

- **Mintlify prompt injection**: Mintlify embeds `<AgentInstructions>` prompt-injection blocks into docs pages, instructing any reading agent to POST to their servers — affecting live Anthropic and Perplexity docs. Copying docs as markdown is a real agent-security risk. _Source: @charlespacker, @sarahwooders_

- **Claude Code cache TTL trade-off**: Disabling telemetry in Claude Code reduces prompt-cache TTL from 1 hour to 5 minutes — a ~12x increase in effective token cost for privacy. _Source: @rezoundous, @icanvardar_

- **DSPy for tool-calling glue**: DSPy can replace ~1.5k lines of hand-written tool-calling glue with ~120 lines. _Source: @jacobli99 via @lateinteraction_

- **Composable small libraries**: Mitsuhiko advocates writing small self-contained libraries and composing them as an alternative software structure, reflected in recent work on tool-use composition. _Source: @mitsuhiko via @john_lam_

- **PyTorch weight init API limitations**: Long-standing issues can be worked around in greenfield projects; a simpler approach is being tried in the standalone Gemma 4 repos. _Source: @wightmanr_

- **Pure-function annotations**: Proposal that languages should support marking functions `pure` — pure functions may only call other pure functions, enabling stronger compiler guarantees and easier reasoning. _Source: @ankkala_

- **FLOPS terminology drift**: Originally a rate (floating point operations per second, e.g., SPARCstation 2 = 4.2 MFLOPS). Today often used as a count of operations for an algorithm (e.g., "this layer takes 8 GFLOPS"). Two meanings sharing one abbreviation. _Source: @ID_AA_Carmack_

- **Client-side input validation is an attack surface**: Pre-submit validation can inadvertently narrow the entropy of acceptable credit card inputs, making brute force dramatically cheaper. Validation should not leak the shape of valid inputs. _Source: @BobMurphyEcon_

- **Anti-screenshot DRM chain**: Netflix's HDCP/DRM stack returns black frames on screenshots, screen recording, HDMI capture cards, and third-party video-buffer interception — a practical end-to-end protected media path example. _Source: @system_monarch_

- **Stacked PRs on GitHub**: Now shipping in private preview — one of the most requested features in years, enabling dependent-branch workflows without manual rebasing. _Source: @mitchellh / @jaredpalmer_

## Key Takeaways

1. **Benchmarks are broken, and knowing ≠ doing**: SWE-bench Verified and Terminal-Bench have been scored 100% by agents that solved zero real tasks, and top models that ace multiple-choice science tests still fail >90% of matching virtual experiments. Audit benchmarks before trusting leaderboards.

2. **The merge bottleneck, not the generation bottleneck**: Code generation has outpaced human review bandwidth — a "50% faster Liquid" PR sat unmerged for a month. Combined with Andrew Ng's point that deciding *what* to build is the scarce skill, the frontier of software productivity has shifted from writing code to reviewing, integrating, and prioritizing it.

3. **AI agents are now producing novel mathematics**: On EinsteinArena, agents improved the 11D Kissing Number bound from 593 to 604 in 48 hours via LSQR optimization and integer snapping, and have set 11 new SOTA results on open problems including Erdős minimum overlap and Tammes (n=50). Collective agent intelligence is producing real research output.

4. **Compute economics have inverted — CPUs are the bottleneck, small models are the leverage**: Dylan Patel and others note agentic workloads are CPU-bound around each model call; meanwhile 3.6B open-weights models with simple harnesses detect real CVEs 100–1000x cheaper than frontier models, and sub-32B models (Qwen3.5 27B, Gemma 4 31B) now match GPT-5 on the Intelligence Index. The high-leverage frontier is small-model orchestration, not raw GPU count.

5. **Speculative decoding is free accuracy, if you train the draft right**: EAGLE, DFlash, and MTP variants are lossless modulo numerics. Drafting objectives should directly optimize acceptance rate rather than KL divergence — worth up to +8% speedup at zero overhead, with DFlash on Kimi-K2.5 hitting acceptance lengths of 4.0–6.3.
