# Learnings - 2026-04-27 14:44

## AI / Machine Learning

- **DeepSeek V4 release & day-0 serving**: V4 ships in two variants — Pro (1.6T params) and Flash (284B) — both with 1M context. SGLang delivered Day-0 support: 199 tok/s on B200 (Pro), 266 tok/s on H200 (Flash) at 4K context, and throughput holds (180/240 tok/s) at 900K. _Source: @swyx ([post](https://x.com/swyx/status/2048126046487322835)), @lm_zheng ([post](https://x.com/lm_zheng/status/2048668672785568160))_
- **DeepSeek V4's real design goal**: V4's "pivotal design goal — at any cost" was *batch invariance*, not 1M context. They stacked ~7 algorithmic tricks plus 15-20 infrastructure hacks to hit it, achievable because they have ~20 world-class competitive programmers and limited compute (a different optimum than frontier labs). _Source: @teortaxesTex ([post 1](https://x.com/teortaxesTex/status/2048329620043210934), [post 2](https://x.com/teortaxesTex/status/2048707398886404524))_
- **Long-context attention scaling in V4**: Only ~10% throughput drop from 4K → 900K context, achieved via hybrid sparse/compressed attention plus serving engineering — 1M context is becoming routine, not aspirational. _Source: @BanghuaZ ([post](https://x.com/BanghuaZ/status/2048647759662858641))_
- **Long-context KV-cache memory math**: For a 40-layer model with 4000 dims and 2 bytes/dim, the KV cache is ~640 KB/token → ~640 GB for 1M tokens. Production answers are GQA/MLA (smaller per-token state) plus interleaved sliding-window attention (cap memory growth per layer); for very long contexts you also need at least one global-attention layer that's bottlenecked by linear memory. _Source: @yoavgo ([post](https://x.com/yoavgo/status/2048382500154572991)), @cHHillee ([post 1](https://x.com/cHHillee/status/2048436723659464773), [post 2](https://x.com/cHHillee/status/2048756662845022655))_
- **Hash routing for MoE**: V4 uses hash layers for expert routing rather than learned gating — a simpler alternative being revisited at production scale. _Source: @AiEleuther ([post](https://x.com/AiEleuther/status/2048239152949280858))_
- **Sinkhorn overhead in MoE**: `sinkhorn_iters=20` in V4 creates significant overhead without specialized kernels — load-balancing algorithms need kernel-level support to be efficient. _Source: @iamgrigorev ([post](https://x.com/iamgrigorev/status/2048751463313105184))_
- **Local frontier-model inference**: A 2-bit selective-quantization GGUF of DeepSeek V4 Flash now runs as a local frontier model on consumer hardware — a meaningful inflection point for edge AI. _Source: @ClementDelangue ([post](https://x.com/ClementDelangue/status/2048397804964348080))_
- **April 2026 LLM release wave**: Gemma 4, GLM-5.1, Qwen3.6, Kimi K2.6, and DeepSeek V4 all shipped this month — useful list to anchor your "current frontier" mental model. _Source: @rasbt ([post](https://x.com/rasbt/status/2048414150527750200))_
- **Gemma 3n's three efficiency tricks**: MatFormer (nested-matryoshka transformer), Per-Layer Embeddings, and KV-Cache Sharing are what let Gemma 3n run on embedded devices vs. Gemma 3. _Source: @gabriberton ([post](https://x.com/gabriberton/status/2048552603760705629))_
- **MatFormer dynamic-width MLPs**: MatFormer trains transformer MLPs so the hidden dimension can be elastically shrunk at inference (e.g., use only the first 1K of 4K neurons under tight budget). It survives this pruning because dynamic budgeting is applied during training — effectively a structured contiguous-neuron dropout. _Source: @gabriberton ([post 1](https://x.com/gabriberton/status/2048552605845225717), [post 2](https://x.com/gabriberton/status/2048552608173019646))_
- **Recurrent Transformer — width beats depth**: At 300M params, an RT with 6 layers but width 2048 beats 12- and 24-layer Transformers on validation cross-entropy, suggesting depth-for-width tradeoffs are underexplored. _Source: @srush_nlp ([post](https://x.com/srush_nlp/status/2048751730167328901))_
- **Implicit CoT via stepwise distillation**: Progressively removing chain-of-thought steps during finetuning lets a 124M GPT-2 Small solve 20×20-digit multiplication at 99.5% accuracy — internalizing reasoning into weights. _Source: @YejinChoinka ([post](https://x.com/YejinChoinka/status/2048632551502451085))_
- **Attention sinks = compression valleys**: Two long-studied LLM phenomena (attention sinks and compression valleys) share a single root cause — massive activations — unifying separate research lines. _Source: @_arohan_ ([post](https://x.com/_arohan_/status/2048044083332149708))_
- **Where Muon comes from**: Muon is essentially a Newton-Schulz iteration giving a fast implementation of Shampoo with the b2=0.0 case — direct intellectual lineage from Bernstein's prior work, not an unrelated invention. _Source: @_arohan_ ([post](https://x.com/_arohan_/status/2048061037476483093))_
- **Muon's hidden cost — miscalibration**: A new "Too Sharp" paper shows Muon-trained models become severely miscalibrated and overconfident on misclassified test examples. A "better optimizer" can shift, not eliminate, failure modes; watch for train-test gap and convergence path-dependency. _Source: @suchenzang ([post](https://x.com/suchenzang/status/2048214282211586337))_
- **PPO uses two regularizers, not one**: Beyond the well-known KL term, the original PPO paper also used an entropy bonus — entropy captures uncertainty over a variable's possible states, encouraging exploration. _Source: @cwolferesearch ([post](https://x.com/cwolferesearch/status/2048084602619568503))_
- **Why deep learning generalizes**: A leading explanation is PAC-Bayes — flat minima found by SGD give favorable PAC-Bayes bounds. _Source: @__paleologo ([post](https://x.com/__paleologo/status/2048602422424080883))_
- **Self-play for LLMs plateaus, but scales with the right algorithm**: Long self-play behaves like RL and stalls. A new method scales better — a 7B model with it solves as many problems as the pass@4 of a 100×-larger model. _Source: @LukeBailey181 via @percyliang ([post](https://x.com/percyliang/status/2048066534740836725))_
- **Mismanaged Geniuses Hypothesis (MGH)**: Boosting GPT-5.2 from 38.7% → 65.6% on LongCoT-mini with no training (just better trajectory management) suggests current models are routinely under-elicited rather than under-capable. _Source: @lateinteraction ([post](https://x.com/lateinteraction/status/2048491059358118002))_
- **Hybrid-attention distillation via KL-guided layer selection**: New ICLR work asks which attention layers are actually worth keeping when distilling a transformer into a hybrid (linear/softmax) attention model. _Source: @soldni ([post](https://x.com/soldni/status/2048125768019087627))_
- **FlashAttention-4 on Blackwell**: Achieves 1,613 TFLOPs/s with 71% hardware utilization — up to 2.7× faster than Triton — and is already integrated into Hugging Face Transformers. _Source: @LambdaAPI ([post](https://x.com/LambdaAPI/status/2048736478310842716)), @tri_dao ([post](https://x.com/tri_dao/status/2048558763247063166))_
- **ARC-AGI scoring caveat**: Without scoring for action efficiency, the top score is 100% — achievable in 20 lines of Python by brute-forcing the state space. Action efficiency is what makes ARC-AGI meaningful. _Source: @fchollet ([post](https://x.com/fchollet/status/2048541240883638574))_
- **Open-world evaluations are next**: Verifiable benchmarks saturate fast. The next frontier is open-world evals over long horizons with intermediate non-verifiable rewards (e.g., running a shop, shipping an iOS app with minimal human help). _Source: @sarahookr ([post 1](https://x.com/sarahookr/status/2048731841759428935), [post 2](https://x.com/sarahookr/status/2048735718097502381))_
- **Continual learning urgency**: Open-world tasks demand model-behavior updates over time while preserving the original goal — making efficiency-aware continual learning a critical research direction. _Source: @sarahookr ([post](https://x.com/sarahookr/status/2048759884125233453))_
- **Build your own evals**: Public benchmarks saturate too quickly to drive product progress. Companies layering on AI should ship internal benchmarks tied to their representative tasks (and consider publishing them, e.g. on Kaggle) — that's how model progress disproportionately benefits *you* rather than commodity tasks. _Source: @OfficialLoganK ([post](https://x.com/OfficialLoganK/status/2048554074107470305)), @_xjdr ([post](https://x.com/_xjdr/status/2048598501739933937)), @nick_kango ([post](https://x.com/nick_kango/status/2048562757080056182))_

## Security

- **Hardcoded API keys in client JS = mass leak**: One GET request using an API key found in page source returned 959 employee emails and 3,165 internal feature flags spanning Home Depot, Fortinet, Autodesk, Tenable, Rakuten, Mayo Clinic, etc. Treat any client-side secret as published. _Source: @weezerOSINT ([post](https://x.com/weezerOSINT/status/2048662702957134199))_
- **Rowhammer on shared KV-cache prefixes**: New paper bit-flips vLLM's shared system-prompt KV cache via Rowhammer. Because the cache doesn't decay, one flipped bit silently corrupts generation for *every* user sharing that prefix — cross-tenant LLM inference now has a hardware-isolation threat surface. _Source: @sakurayukiai ([post](https://x.com/sakurayukiai/status/2048161085618893046))_
- **Isolated guest VLANs reveal compromised IoT**: Putting visitors' devices on an isolated VLAN exposed intrusion attempts every 20 minutes — likely from already-compromised consumer devices probing the LAN. Treat any unknown device as actively hostile. _Source: @tritlo ([post](https://x.com/tritlo/status/2048294676373860552))_
- **Suspicious port-knock = vendor backdoor signature**: A wifi router accepting an unauthed UDP packet on port 20002 to add a Dropbear SSH firewall rule on TCP 20001 — but only when the country code is set to Singapore — is the signature of a vendor-installed remote-access backdoor. _Source: @moyix ([post](https://x.com/moyix/status/2048740270410178653))_
- **Cognitive security as a development priority**: ICLR 2026 position paper argues AI development should treat cognitive security (defending users' reasoning processes from manipulation by AI systems) as a first-class objective alongside traditional safety/alignment. _Source: @james_y_zou ([post](https://x.com/james_y_zou/status/2048441855298441338))_
