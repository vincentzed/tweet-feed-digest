# Learnings - 2026-05-19 05:52

## AI / Machine Learning

- **Bitter lesson, restated**: "Don't be distracted by human knowledge, as AI has been historically. Instead focus on methods for creating knowledge that scale with computation, like search and learning." — Richard Sutton in 26 words. _Source: @swyx ([post](https://x.com/swyx/status/2056474158369042803))_
- **Coding agents as a constraint problem**: Treat coding agents as "blind squirrels running into a maze and bumping into walls" — your job is to place verifiable constraints (walls) strategically so they converge to the right region. _Source: @fchollet ([post](https://x.com/fchollet/status/2056401102485266620))_
- **Coding agents vs research agents**: Coding agents are largely a solved direction; research agents — agents that can autonomously discover new knowledge — remain an open problem. _Source: @rohan_virani via @sarahcat21 ([post](https://x.com/sarahcat21/status/2056530951526821897))_
- **Coding-agent prompt pattern**: Ask agents to keep a running `implementation-notes.html` (or markdown) file that logs decisions made outside the spec, tradeoffs, and changes — surfaces what you'd otherwise have to dig out of diffs. _Source: @trq212 ([post](https://x.com/trq212/status/2056415973125796184))_
- **MoE design reduces to two variables**: A study training >2000 MoE LMs ("Slicing and Dicing MoEs") finds expert size and count dominate; shared experts, routing schemes, and token dropping contribute less than commonly assumed. _Source: @margs_li via @LukeZettlemoyer ([post](https://x.com/LukeZettlemoyer/status/2056465724470874495))_
- **Sparse attention without training (BLASST)**: MLSys 2026 Best Paper introduces a training-free dynamic sparse attention mechanism that uses a single scalar threshold on online softmax statistics to skip negligible attention blocks — runtime statistics alone can drive efficient inference-time sparsity. _Source: @jiayiy via @hsu_byron ([post](https://x.com/hsu_byron/status/2056277234495983904))_
- **Pedagogical RL insight**: An MIT method shows that *correct* reasoning traces can still be *bad* training data — analogous to how a teacher's worked example may produce correct outputs but obscure the actual learning signal. _Source: @blc_16 via @lateinteraction ([post](https://x.com/lateinteraction/status/2056447787621830686))_
- **Multi-agent reasoning, when it helps**: Multi-agent setups don't beat single LLMs at the same budget (e.g. 10K thinking tokens) because that's comfortably within one call's capability. The payoff appears when you need to generate ~1M tokens of reasoning. _Source: @prfsanjeevarora ([post](https://x.com/prfsanjeevarora/status/2056506472071393672))_
- **Late-interaction retrieval optimization**: ColBERT/PyLate-style retrieval bottlenecks on materializing the full similarity matrix. The MaxSim kernel avoids this with tiled scoring using `simdgroup_matrix` (Metal) and WMMA, achieving 3–5× speedup over a naive implementation. _Source: @ErikKaum via @ClementDelangue ([post](https://x.com/ClementDelangue/status/2056348609046548493))_
- **AI aphasia parallels**: When researchers "damage" language models, the resulting symptoms mirror human aphasia patterns — though the distributions differ. Suggests overlap between artificial and biological language processing mechanisms. _Source: @nrol_ling via @StanfordAILab ([post](https://x.com/StanfordAILab/status/2056461442157879356))_
- **Diffusion LMs for inference**: Diffusion language models are being explored as a path to faster inference relative to autoregressive transformers — featured at MLSys 2026. _Source: @volokuleshov via @StefanoErmon ([post](https://x.com/StefanoErmon/status/2056459724170870920))_
- **Synthetic coding-problem curation**: FrontierSmith demonstrates AI-generated open-ended coding problems can outperform human-expert curation at scale, suggesting open-ended training data is no longer the bottleneck it was. _Source: @MangQiuyang via @StanfordAILab ([post](https://x.com/StanfordAILab/status/2055893042029322589))_
- **Agent rollout infrastructure (NanoRollout)**: Digital-agent RL is bottlenecked by slow, heavy environments. NanoRollout is a 900-line open core infrastructure for scaling rollouts under workloads as varied as large agent and tool-use training. _Source: @JunliWang2021 via @BanghuaZ ([post](https://x.com/BanghuaZ/status/2056590630281945354))_
- **Causal models from action, not observation**: Kids construct causal models through intrinsically motivated action — something current LLMs notably do not do, since they learn from passive observation alone. _Source: @AlisonGopnik via @berkeley_ai ([post](https://x.com/berkeley_ai/status/2056172868199965178))_
- **Autonomous exploration as a trainable capability**: Meituan's "Explore-then-Act" paper argues task-oriented RL does *not* produce exploration as a side effect — you have to measure and train the agent's ability to discover its environment explicitly. _Source: @gm8xx8 ([post](https://x.com/gm8xx8/status/2056215373138014519))_
- **VLM design — simplicity wins**: Many VLM papers propose elaborate new connectors and claim gains, but follow-ups just replace them; Gemma 4 continues the pattern. Notably, both InternVL3.5 and GLM-4.5V use an MLP as their vision-to-language connector — a recurring architectural pattern. _Source: @gabriberton ([posts](https://x.com/gabriberton/status/2056232439933194709), [post](https://x.com/gabriberton/status/2056232613439050217))_
- **2023 vs 2026 model UX thesis**: The "model should be invisible" framing from 2023 has flipped — by 2026 the alpha is in agent behavior, continual-learning loops, and making models feel natural. UX is back in. _Source: @joannejang ([post](https://x.com/joannejang/status/2056440601273577515)), via @_arohan_ ([post](https://x.com/_arohan_/status/2056441198534066230))_
- **Local + frontier hybrid pattern**: Running autoresearch with a local Qwen 3.6 26B works well if you give it an "advisor" extension that periodically queries a frontier model (e.g. GPT 5.5) for ideas — cheap base loop, expensive ideation. _Source: @tobi ([post](https://x.com/tobi/status/2056198717225464307))_
- **SDAR (Self-Distilled Agentic RL)**: A hybrid approach combining GRPO's sparse trajectory-level RL with privileged self-distillation from OPSD, applied to multi-agent systems. _Source: @novasarc01 ([post](https://x.com/novasarc01/status/2056007170110394849))_
- **Synthetic RL environment scale**: Prime Intellect's General-Agent is a self-evolving environment with 4,504 tool-use tasks, 1,040 domains, and 8,159 unique tools — task corpus grows harder over time automatically. _Source: @PrimeIntellect ([post](https://x.com/PrimeIntellect/status/2056569877167808966))_
- **Fine-tuning a 13B model on a phone**: Tether fine-tuned a 13B parameter model on an iPhone 16 — concrete proof that on-device fine-tuning at this scale is now achievable. _Source: @TechCrunch ([post](https://x.com/TechCrunch/status/2049260325136961857))_
- **AlphaFold2 + LLM autoresearch**: GPT 5.5 has been running "goal mode" for 150+ hours searching for topologically inspired architectural improvements to AlphaFold2 — performance is improving. Early evidence LLMs can drive open-ended structural-biology research. _Source: @charliermarsh ([post](https://x.com/charliermarsh/status/2055987670040412383))_
- **Hierarchical world models timeline**: Yann LeCun predicts a general method for training hierarchical world models from video and real-world data within 12–18 months, to be scaled toward a universal world model. _Source: @ylecun ([post](https://x.com/ylecun/status/2056020151053492412))_
- **Agent evaluation is the production gate**: Detailed evaluation of agents — fundamentals, common frameworks, benchmark case studies — is the difference between demoware and production. _Source: @cwolferesearch ([post](https://x.com/cwolferesearch/status/2056399847553409301))_
- **RoPE → trilinear**: Rotary positional embedding extends naturally to a trilinear product, an elegant generalization worth knowing for anyone designing attention variants. _Source: @_arohan_ ([post](https://x.com/_arohan_/status/2056257204584607819))_

Cross-org compute deals are becoming visible. _Source: @cursor_ai ([post](https://x.com/cursor_ai/status/2056415413077233983)), @elonmusk ([post](https://x.com/elonmusk/status/2056422097237283295))_

## Software Engineering

- **Assert everywhere in ML Python**: Duck typing is dangerous in deep-learning code — passing a list when a tensor is expected gives a weird downstream bug instead of a clean error, and wastes agent tokens debugging. Add `assert isinstance(x, torch.Tensor)` liberally. _Source: @gabriberton ([posts](https://x.com/gabriberton/status/2056381648707735875), [post](https://x.com/gabriberton/status/2056382698189734103))_
- **jaxtyping + beartype**: Combining `jaxtyping` (shape and dtype annotations) with `beartype` (runtime type checking) gives a practical way to enforce tensor-shape contracts in Python ML code at runtime. _Source: @abcamiletto / @typesuser via @gabriberton ([post](https://x.com/gabriberton/status/2056387528694136989))_
- **`pip install vllm` on ARM64 GPUs now works**: PyTorch 2.11.0 fixed a long-standing aarch64 install headache, so installing vLLM on GH200, GB200, and GB300 systems no longer requires `--index-url` flags or risks pulling CPU wheels by mistake. _Source: @vllm_project ([post](https://x.com/vllm_project/status/2056518948829692096))_
- **Bun's Rust rewrite is winning**: On the "bundle Three.js 10x with minification + sourcemaps" benchmark, Bun's Rust port is now ~10% faster than the original Zig implementation. _Source: @jarredsumner ([post](https://x.com/jarredsumner/status/2056311676253950459))_
- **uv binary slimming**: Astral cut ~2% off the uv binary by removing and consolidating dependencies — concrete reminder that dependency hygiene pays off in distribution size. _Source: @charliermarsh ([post](https://x.com/charliermarsh/status/2056487621719662612))_
- **The monolith returns**: As LLMs make it cheap to rewrite and understand large foreign codebases, the incentive to break software into many small dependencies declines — expect shorter supply chains and a return to monoliths. _Source: @ClementDelangue ([post](https://x.com/ClementDelangue/status/2056404895985504418))_
- **Missing API ergonomics**: LLM vendors do not return per-request token costs as HTTP response headers, forcing every client to compute it from token usage. A consistent industry-wide ask. _Source: @zeeg ([post](https://x.com/zeeg/status/2056431505514344629))_
- **Stroustrup on AI-generated code**: Bjarne Stroustrup says AI-generated code currently produces more bugs, bloat, and security holes, and is nearly impossible to validate — small prompt changes drift outputs in hard-to-test ways. _Source: @JosephJacks_ ([post](https://x.com/JosephJacks_/status/2056572054410018874))_
- **VyOS docs rebuilt for AI consumption**: MyST Markdown + Opus AI reviewers + Context7 integration produces branch-aware, machine-readable documentation — a template for AI-assisted developer-tool docs. _Source: @vyos_dev ([post](https://x.com/vyos_dev/status/2054914358988194130))_

## Key Takeaways

- **Bitter lesson, restated for 2026**: Methods that scale with compute (search + learning) beat methods that encode human knowledge. Build for compute scaling, not cleverness. _Source: @swyx ([post](https://x.com/swyx/status/2056474158369042803))_
- **Coding agents need walls, not instructions**: Treat agents as blind squirrels in a maze — your leverage is in placing verifiable constraints strategically, not in writing better natural-language prompts. _Source: @fchollet ([post](https://x.com/fchollet/status/2056401102485266620))_
- **MoE design reduces to two variables**: Across 2000+ trained MoEs, expert size and count dominate; routing tricks and shared experts matter less. And correct ≠ good RL training data — correct reasoning traces can still teach the wrong thing. _Source: @margs_li via @LukeZettlemoyer ([post](https://x.com/LukeZettlemoyer/status/2056465724470874495)), @blc_16 via @lateinteraction ([post](https://x.com/lateinteraction/status/2056447787621830686))_
