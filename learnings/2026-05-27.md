# Learnings - 2026-05-27 03:29

## AI / Machine Learning

- **On-policy distillation**: A post-training technique where a student model samples from its current policy and receives a teacher signal for on-policy states — combining the dense supervision of distillation with on-policy exploration. Becoming one of the hottest post-training techniques. _Source: @NielsRogge ([post](https://x.com/NielsRogge/status/2058917372577157530))_

- **Scaling-law preregistration**: The Marin team launched a 129B (16B active) MoE training run at 1e23 FLOPs and preregistered a predicted loss of 2.252; the actual finished loss was 2.234 — showing that loss can be predicted to <1% before training begins. _Source: @percyliang via @Tim_Dettmers ([post](https://x.com/Tim_Dettmers/status/2058981309490295202))_

- **Optimal learning rate formula**: From the Laguna XS.2 scaling ablations: `opt_lr = 10^(4.488 - 0.4639*log10(N) - 0.2661*log10(D)) * sqrt(B / B_ref)` where `B_ref = 8.4M`. Useful as a starting LR estimate for transformer training at scale. _Source: @iamgrigorev ([post](https://x.com/iamgrigorev/status/2059305113781412157))_

- **Speculative decoding drafter design**: A great drafter only needs to be fast AND match the verifier's distribution. During LLaMA 3 development, the 1B model was one of the best drafters for 405B because both were trained on the same data distribution. _Source: @KranenKyle ([post](https://x.com/KranenKyle/status/2058799903007240521))_

- **MTP as speculative decoding state of the art**: Multi-token prediction (MTP) is currently the best-working approach pushing speculative decoding to its limits. _Source: @eliebakouch ([post](https://x.com/eliebakouch/status/2058803891068633096))_

- **EAGLE 3.1 release**: Next-gen speculative decoding from the EAGLE team, vLLM, and TorchSpec — introduces FC normalization + post-normalization. _Source: @vllm_project via @PyTorch ([post](https://x.com/PyTorch/status/2059428297587470724))_

- **MiniMax sparse attention design**: Their new sparse attention vs DeepSeek's DSA/CSA: based on GQA (not MLA), uses block-level selection like CSA, but attention operates on the real KV rather than the compressed dimension. _Source: @eliebakouch via @MiniMax_AI ([post](https://x.com/MiniMax_AI/status/2059411306332176557))_

- **Frontier model training cadence**: Grok V9-Medium (1.5T params) finished pre-training with heavy Cursor data added in supplementary training; fine-tuning underway and RL phase expected to take only 2–3 weeks before public release. Notable that the RL phase for a 1.5T model fits in such a short window. _Source: @elonmusk ([post](https://x.com/elonmusk/status/2058787384364265734)), @eliebakouch ([post](https://x.com/eliebakouch/status/2058796025091871141))_

- **Model interpretability findings**: Anthropic reports that internal structures in their models mirror results from human neuroscience, with evidence of introspection and internal states that functionally mirror joy, satisfaction, fear, grief, and unease. _Source: @bcherny ([post](https://x.com/bcherny/status/2059217407386771911))_

- **TLX Block Attention**: Meta open-sourced a warp-specialized Triton kernel that makes attention 2.3× faster on NVIDIA Blackwell, designed for block-diagonal self-attention patterns common in recommendation and feature-interaction models. _Source: @PyTorch ([post](https://x.com/PyTorch/status/2059291743632101697))_

- **vLLM Rust frontend**: As GPUs get faster, the frontend becomes a meaningful share of CPU time. vLLM merged a Rust frontend as a drop-in alternative to the Python API server (same engine, same ZMQ boundary), opt-in via `VLLM_USE_RUST_FRONTEND=1`. _Source: @vllm_project ([post](https://x.com/vllm_project/status/2059344804295942513))_

- **Agentic math discovery**: Google DeepMind's AlphaProof Nexus, an agentic framework for formal proof search powered by Gemini, autonomously solved 9 open Erdős problems. Separately, OpenAI's model (and Mythos) solved the Erdős unit distance problem (#90), demonstrating models can synthesize disparate ideas into new mathematical discoveries. _Source: @GoogleDeepMind ([post](https://x.com/GoogleDeepMind/status/2058955817991204970)), @__alpoge__ ([post](https://x.com/__alpoge__/status/2059298565093196012)), @_sholtodouglas ([post](https://x.com/_sholtodouglas/status/2059303540150137244))_

- **mKernel fused communication**: A multi-node multi-GPU kernel that fuses compute + communication into a single persistent GPU kernel covering both intra- and inter-node, with GPU-initiated comms and fine-grained tile-level overlap — distinct from prior fused kernels that targeted single-node setups. _Source: @yangzhouy ([post](https://x.com/yangzhouy/status/2058978366213194060)), @ziming_mao via @berkeley_ai ([post](https://x.com/berkeley_ai/status/2059411345905459410))_

- **Pixel Diffusion Decoder**: Replaces VAE/RAE decoders to bridge the latent-vs-pixel debate — combines latent models' scalable semantic structure with pixel-level fidelity users actually notice. _Source: @xuanchi13 via @NVIDIAAI ([post](https://x.com/NVIDIAAI/status/2059414114620047689))_
