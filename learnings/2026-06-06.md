# Learnings - 2026-06-06 17:40

## AI / Machine Learning

- **AI-designed model architectures**: Vortex is a sparse-attention mechanism *discovered by AI agents* rather than hand-designed, preserving accuracy while raising throughput — reported 4.7× faster on GLM-4.7-Flash (MLA), 1.37× on MiniMax-M2.7 (229B), and 3.46× on an agent-discovered Qwen3-1.7B variant — and it already runs in SGLang. It hints at recursive self-improvement, where the bottleneck shifts from "can the agent code?" to "can we still steer it?" _Source: @InfiniAILab via @lm_zheng ([post](https://x.com/lm_zheng/status/2063084444957966703)), @BeidiChen ([post](https://x.com/BeidiChen/status/2062984489530429787)), @BanghuaZ ([post](https://x.com/BanghuaZ/status/2063079700562583829))_
- **Sparse attention scaling**: Log-linear Sparse Attention (LLSA) is a *trainable* sparse-attention mechanism that cuts attention complexity from O(N²) to O(N log N), making diffusion transformers substantially more efficient. _Source: @ccloy ([post](https://x.com/ccloy/status/2063039782955962492))_
- **Hybrid Transformer-Mamba MoE at scale**: NVIDIA Nemotron 3 Ultra is a 550B-parameter Transformer-Mamba hybrid with mixture-of-experts and only 55B active parameters, a 1M-token context, MMLU 89.1, and is built specifically for long-running autonomous agents; its NVFP4 variant claims ~5× throughput — illustrating how state-space/MoE hybrids plus low-precision formats push inference efficiency. _Source: @JosephJacks_ ([post](https://x.com/JosephJacks_/status/2063295431074025651)), @bernhardsson ([post](https://x.com/bernhardsson/status/2062657918898446474))_
- **Quantization-Aware Training for on-device**: Google's Gemma 4 QAT checkpoints (all sizes + drafters) keep quality higher than standard post-training quantization at the same compression ratio, baking quantization into training so the model tolerates low-precision deployment — shrinking Gemma 4 E2B to ~1GB with a mobile-specialized format. _Source: @julien_c (RT @googlegemma) ([post](https://x.com/julien_c/status/2062953819177156877)), @ying11231 ([post](https://x.com/ying11231/status/2062986319463358522))_
- **Open-weight transcription is still behind frontier**: Gemma 4 12B can transcribe but scores only 8.8% on AA-WER (#58), a concrete reminder that adding a modality ≠ being competitive on it. _Source: @ArtificialAnlys ([post](https://x.com/ArtificialAnlys/status/2063059212532642193))_
- **Multi-teacher on-policy distillation (MODP)** is now standard post-training: the multi-teacher SFT→RL recipe was established by DeepSeek R1 and has been widely adopted (e.g., NVIDIA), signaling convergence on post-training methodology across labs. _Source: @stanfordnlp (RT @natolambert) ([post](https://x.com/stanfordnlp/status/2062925905039855686))_
- **Streaming, controllable TTS**: Higgs Audio v3 is a ~4B chat-native text-to-speech model on a Qwen3-4B backbone with interleaved text/audio tokens, so synthesis can begin before a full sentence arrives — a design pattern for real-time voice agents. It supports 100 languages with single-digit WER/CER and inline control over emotion, style, prosody, and sound effects, with open weights. _Source: @boson_ai ([post](https://x.com/boson_ai/status/2062629221411995896)), @ying11231 ([post](https://x.com/ying11231/status/2062744213134188977))_
- **Pixel-space diffusion**: NVIDIA's PixelDiT (CVPR 2026 best-paper finalist) runs diffusion directly in pixel space, avoiding the quality loss a pretrained autoencoder injects when it compresses images before diffusion — loss that otherwise accumulates across the whole generation pipeline. _Source: @NVIDIAAI ([post](https://x.com/NVIDIAAI/status/2063034422698389625))_
- **Cheaper diffusion sampling via polynomial approximation**: Diffusion sampling can be accelerated by estimating features with Chebyshev polynomials instead of running costly full network evaluations at each step, yielding large speedups while maintaining quality. _Source: @StefanoErmon via @StanfordAILab ([post](https://x.com/StanfordAILab/status/2062772144992330159))_
- **Flow matching for unpaired data→data tasks**: Much of science needs unpaired translation (untreated → post-intervention cells, low- → high-redshift galaxies). Flow matching can do this in principle, but its quality degrades sharply in high dimensions — an active limitation to be aware of. _Source: @shiye_su via @StanfordAILab ([post](https://x.com/StanfordAILab/status/2063281274605670497))_
- **Optimizer geometry intuition**: "Anisotropy is good for the forward pass and isotropy is good for the backward pass" — a compact heuristic about how directional structure in representations/gradients helps differently in each direction. _Source: @_arohan_ ([post](https://x.com/_arohan_/status/2062980541830586798))_
- **RL infra is shifting from "engine mode" to "server mode"**: Modern RL frameworks (e.g., slime, AstraFlow) are decoupling rollout/inference from training, treating them as independently managed services — argued to be the right abstraction for the agentic era. AstraFlow v0.1.1 even reproduces a recipe where models learn to spawn sub-agents for coding tasks, modeling hierarchical agentic behavior. _Source: @slime_framework via @BanghuaZ ([post](https://x.com/BanghuaZ/status/2062932936408936900)), @InfiniAILab via @BanghuaZ ([post](https://x.com/BanghuaZ/status/2063079757345128507)), @BeidiChen via @tqchenml ([post](https://x.com/tqchenml/status/2063224257232969916))_
- **LLMs as scientific instruments**: Claude Opus 4.7 matches and on some tasks beats dedicated NMR-spectroscopy software at inferring molecular structure — evidence that frontier models can replace specialized scientific tooling in narrow domains. _Source: @AnthropicAI ([post](https://x.com/AnthropicAI/status/2062979607448682731))_
- **Discovering scientific models from data**: DataDIVER (Google DeepMind Neuroscience Lab) automatically discovers concise computational models directly from data, surfacing mechanistic hypotheses and generating testable predictions — an example of AI for scientific model discovery. _Source: @kevinjmiller10 via @demishassabis ([post](https://x.com/demishassabis/status/2062619496716595288))_
- **LLM reliability is conditional on the prompt and domain**: Frontier models report current news reliably when asked clear, precise questions, but accuracy drops substantially for underspecified queries and for news in underrepresented regions and languages (e.g., Hindi). _Source: @james_y_zou ([post](https://x.com/james_y_zou/status/2062919238650929432))_
- **"Data leak" reports were convincing hallucinations**: Long-standing reports of an LLM API "leaking customer data" were investigated and found to be very specific, very plausible *hallucinations*, not real leaks — a caution against trusting realistic-looking model output as ground truth. _Source: @MoritzW42 ([post](https://x.com/MoritzW42/status/2062930461802811720)), @thdxr ([post](https://x.com/thdxr/status/2062972544190194147))_
- **Measuring AI overreliance**: The "Offloading Score" quantifies how much cognitive work a user hands to AI by simulating how each step would have been done without it, then counting the steps the AI saved — a concrete metric for cognitive offloading. _Source: @Diyi_Yang via @StanfordAILab ([post](https://x.com/StanfordAILab/status/2063022055357141392))_
- **Benchmarks that co-evolve with models**: Because static benchmarks inevitably saturate as models improve, harder validated task variants can be evolved automatically alongside frontier models — doubling as RL training data for self-improvement. _Source: @dawnsongtweets via @berkeley_ai ([post](https://x.com/berkeley_ai/status/2063032648348688666))_
- **Eval horizon is a real differentiator**: METR's agentic evals cap at ~16 hours of task length, whereas Cognition reports private enterprise evals up to 100 hours — task duration is becoming a key axis for measuring agent capability. _Source: @swyx ([post](https://x.com/swyx/status/2062611218196771017))_
- **Two shapes of progress**: Advances come either as a single 3× jump or as a series of stacked ~20% micro-improvements; the hard, underrated work is ensuring the small gains actually compound rather than cancel. _Source: @percyliang ([post](https://x.com/percyliang/status/2062919606403313680))_
- **AI in mathematics research**: An OpenAI model found a counterexample to an 80-year-old Erdős conjecture, and researchers report current LLMs can now contribute genuinely new ideas to theory problems — some mathematicians say GPT-5.x-class models already prove many theorems for them, though it's underdiscussed because researchers want to publish under their own names first. _Source: @polynoamial (RT @OpenAI) ([post](https://x.com/polynoamial/status/2062668663317246451)), @suchenzang ([post](https://x.com/suchenzang/status/2063135555735671028)), @DominikPeters via @polynoamial ([post](https://x.com/polynoamial/status/2063059064549159195))_
- **Domain preference is uneven**: In a Stanford study, law professors strongly preferred Gemini 2.5 Pro's answers over their peers' on legal tasks — yet practitioners report LLMs are weaker at creative fiction writing, suggesting models excel where output structure is judged more than prose quality. _Source: @suchenzang ([post](https://x.com/suchenzang/status/2062906582024028619))_
- **Prompting technique**: Framing a task as a *question* rather than a command invites the model to push back, rate the idea, and suggest alternatives — often better than rigid "plan mode," since what you literally said is frequently not what you meant. _Source: @swyx ([post](https://x.com/swyx/status/2063082950317486133))_
- **"Agent-ready" ≠ scrapable**: A site is agent-ready when it exposes *typed tools* (search, checkout, inventory) an agent can call directly — not merely HTML an agent can scrape. _Source: @CoolestAK87 ([post](https://x.com/CoolestAK87/status/2059678645531062683))_
- **Sample efficiency over token efficiency**: An argument that the industry over-optimizes token efficiency for "perverse reasons," when the more important metric for progress is sample efficiency — how much a model learns per example. _Source: @JosephJacks_ ([post](https://x.com/JosephJacks_/status/2063248088488395126))_
- **Limits on recursive self-improvement**: Against claims that AI is on a fast path to recursive self-improvement, critics note that real-world processes have irreducible time constants — you can't run experiments, manufacturing, or physics faster than real time — bounding any exponential takeoff. _Source: @AnthropicAI (RT via @bcherny) ([post](https://x.com/bcherny/status/2063284026086232349)), @ylecun ([post](https://x.com/ylecun/status/2063242146593841645)), @Dan_Jeffries1 ([post](https://x.com/Dan_Jeffries1/status/2062811669604991120))_
- **Code volume is not productivity**: Reports that AI lets engineers "ship 8× more code" drew the rebuttal that lines/volume of code is a poor productivity proxy, and that "percent of code read/reviewed by a human" may be more meaningful. Relatedly, measuring an engineer's productivity by token consumption (and handing everyone a fixed token budget) is argued to be a flawed proxy that misaligns incentives. _Source: @bcherny ([post](https://x.com/bcherny/status/2063284071770579196)), @fchollet ([post](https://x.com/fchollet/status/2063288883052491011)), @charliermarsh ([post](https://x.com/charliermarsh/status/2062608530620682590)), @ScottWu46 via @ramin_m_h ([post](https://x.com/ramin_m_h/status/2062609990834098593))_

## Software Engineering

- **Coding agents need "harnesses," not rule lists**: Using agents effectively means embracing their stochastic nature and building a framework for them to reason, rather than dumping a large pile of static rules. Harness engineering and knowledge-base curation explicitly cannot rely on all information being pulled into context. _Source: @_lopopolo via @lateinteraction ([post](https://x.com/lateinteraction/status/2063046763263520799))_
- **Getting agents to use tools is a teachable "skill issue"**: A recurring obstacle is that coding agents won't reliably use a new tool (e.g., Langfuse) until explicitly taught how — tool adoption by agents is harder than expected and is itself an engineering task. _Source: @aiDotEngineer via @swyx ([post](https://x.com/swyx/status/2062953893278212546))_
- **Incognito detection via storage quota**: You can fingerprint Chrome Incognito by writing ~512 tiny 1-byte entries into a Cache API cache, then reading `navigator.storage.estimate().usageDetails.caches` — normal Chrome reports ~393 KB (rounded to a quota bucket) while Incognito reports ~85 KB, because private mode allocates a much smaller storage budget. _Source: @alain ([post](https://x.com/alain/status/2062628128493916227))_
- **Competing agent-config standards**: Codex reads `AGENTS.md` while Claude Code reads `CLAUDE.md`; there is no shared industry standard for agent project instructions, creating real friction for repos used with multiple tools. _Source: @theo ([post](https://x.com/theo/status/2062741740910702764))_
- **AI coding tools are converging**: A side-by-side feature timeline shows Claude Code and Codex shipping near-identical features (`/goal`, side conversations, subagents, and a "dreaming"/memory-synthesis feature), with OpenAI's "Dreaming" auto-synthesizing memory for ChatGPT. _Source: @eliebakouch ([post](https://x.com/eliebakouch/status/2062693979087397189))_
- **Python tooling adoption**: Ruff is at ~243M PyPI installs/month (+100% since February), uv at ~165M (+100%), and ty at ~30M (+300%); uv served another 172M installs from its own CDN (337M total in 30 days) — a useful proxy for how fast the Rust-based Python toolchain is displacing incumbents. _Source: @charliermarsh ([post](https://x.com/charliermarsh/status/2062648448646521311))_
- **Open-source governance under strain**: The Ladybird browser has stopped accepting public pull requests, a concrete signal that open-source contribution dynamics are shifting (partly under AI-generated-PR load). _Source: @charliermarsh ([post](https://x.com/charliermarsh/status/2062910752541823226))_
- **Acquisitions vs. project independence**: After Evan You's team was acquired, he clarified Vue is *not* part of the deal and remains independent — though the acquisition lets him better fund Vue contributors, a useful distinction between a maintainer's employment and a project's ownership. _Source: @evanyou ([post](https://x.com/evanyou/status/2062767662917451803))_
- **Native mobile auth in Expo**: Clerk Expo 3.1 ships `AuthView`, `UserButton`, and `UserProfileView` as native components built on SwiftUI and Jetpack Compose (wired via config plugin), removing the old need for WebViews or hand-built auth UI in Expo apps. _Source: @clerk ([post](https://x.com/clerk/status/2049221455930622073))_
- **Zig's new I/O model**: Concurrency and async runtimes are an active PL research area driven by performance; Zig's new I/O model is a concrete example worth studying for its low-level mapping to the OS. _Source: @ekzhang1 ([post](https://x.com/ekzhang1/status/2062730414884552736))_

## Systems & Infrastructure

- **A hackable CUDA matmul template can rival cuBLAS**: A concise, hackable tcgen05 (Blackwell tensor-core) kernel "template" matched cuBLAS performance not by chasing peak speed but by being easy to fork — bring your own epilogues, roll a megakernel, or have an agent modify it. These kernels port naturally to CuteDSL for those comfortable with PTX, with working BF16 MMA mainloop plus MXFP8 and NVFP4 examples — a practical entry point for low-precision GEMM kernel work. _Source: @gaunernst ([post](https://x.com/gaunernst/status/2063271110930796620)), code ([post](https://x.com/gaunernst/status/2063271116081348916))_
- **NVPTX backend docs as a CuTe DSL reference**: LLVM's NVPTX backend documentation is an underrated quick reference for the `llvm.nvvm.*` intrinsics that the CuTe DSL lowers to — useful for seeing what the NVVM backend actually emits under the hood. _Source: @SubhoGhosh02 ([post](https://x.com/SubhoGhosh02/status/2062774768928174233))_
- **Rethinking silicon under wafer constraints**: Today's process nodes are optimized for maximum performance *per wafer*, but if the world becomes wafer-supply-constrained, chip designs could trade some per-chip performance for fewer layers / higher wafers-per-year throughput — a different optimization target than raw speed. _Source: @ID_AA_Carmack ([post](https://x.com/ID_AA_Carmack/status/2062965118074233256))_
- **One engine, research to prod**: vLLM is Google's recommended way to serve Gemma 4 QAT checkpoints, reinforcing that a single open-source inference engine spanning research and production is increasingly the default deployment path. _Source: @vllm_project ([post](https://x.com/vllm_project/status/2062938949560283216))_
- **Modal as a "virtual cluster"**: Modal is built from raw cloud resources into a single virtual cluster, which turns "it works on my machine" into "it works on our machine" — a model for reproducible distributed compute environments. _Source: @charles_irl ([post](https://x.com/charles_irl/status/2062969512119751035))_
- **Running frontier models on Apple Silicon via MLX quants**: Nemotron 3 Ultra and Nano can run locally on Apple Silicon using MLX quantizations built from the official BF16 release, available in 4-, 5-, 6-, and 8-bit variants. _Source: @pipenetwork ([post](https://x.com/pipenetwork/status/2063237324612235432))_
- **Context hygiene cuts AI cost more than hardware**: The cheapest way to reduce an AI bill is often not a faster chip, smaller model, or clever quantization, but giving the model a "cleaner desk" — e.g., Karpathy's Obsidian knowledge base of clean markdown folders the model can pull from. _Source: @demian_ai via @nebiustf ([post](https://x.com/nebiustf/status/2063059020030808149))_

## Key Takeaways

1. **AI is starting to design AI systems**: Vortex shows agents discovering novel sparse-attention architectures that match accuracy while delivering up to 4.7× throughput gains and run in production serving stacks like SGLang — moving "AI building AI" from theory toward reality, where the bottleneck becomes steering rather than coding. _Source: @InfiniAILab via @lm_zheng ([post](https://x.com/lm_zheng/status/2063084444957966703)), @BanghuaZ ([post](https://x.com/BanghuaZ/status/2063079700562583829))_
2. **Efficiency is the dominant research theme this cycle** — sub-quadratic attention (LLSA, O(N log N)), hybrid Transformer-Mamba MoE with sparse activation (Nemotron 3 Ultra), QAT for on-device, and pixel/polynomial-accelerated diffusion all attack the same problem: more capability per FLOP/byte. _Source: @ccloy ([post](https://x.com/ccloy/status/2063039782955962492)), @JosephJacks_ ([post](https://x.com/JosephJacks_/status/2063295431074025651)), @ying11231 ([post](https://x.com/ying11231/status/2062986319463358522))_
3. **Clean context beats better hardware for cutting AI costs**: the highest-leverage cost reduction is often giving models a well-organized knowledge base (clean markdown, a curated wiki) and treating agents as stochastic reasoners you build a harness around — not a faster chip or a giant pile of static rules. _Source: @demian_ai via @nebiustf ([post](https://x.com/nebiustf/status/2063059020030808149)), @_lopopolo via @lateinteraction ([post](https://x.com/lateinteraction/status/2063046763263520799))_
4. **Distrust output that's measured by the wrong yardstick**: a year of "API leaking customer data" reports turned out to be convincing hallucinations, while LLM reliability degrades on underspecified prompts and underrepresented languages — and "8× more code" or token consumption are poor productivity proxies versus human-reviewed-code and outcomes. _Source: @MoritzW42 ([post](https://x.com/MoritzW42/status/2062930461802811720)), @james_y_zou ([post](https://x.com/james_y_zou/status/2062919238650929432)), @fchollet ([post](https://x.com/fchollet/status/2063288883052491011))_
5. **A "no" from a top VC predicts almost nothing**: Sequoia passed on Cloudflare, a16z and Khosla passed on later winners — founders should treat rejection as low-signal and keep building. _Source: @eastdakota ([post](https://x.com/eastdakota/status/2062860530360959273)), @GergelyOrosz ([post](https://x.com/GergelyOrosz/status/2062930213344821421))_
